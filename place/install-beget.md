# Place v13 — установка на хостинг (Beget). Пошагово от А до Я

Серверная версия: все данные лежат в базе на хостинге, вход с любого устройства,
ночной автосбор Wordstat и ежедневные резервные копии делает сам сервер.

## Что в комплекте

| Файл | Что это |
|---|---|
| `index.html` | Приложение (интерфейс). Загружается в public_html |
| `api.php` | Сервер: вход, данные, Wordstat, бэкапы |
| `config.sample.php` | Шаблон настроек. Копируете в `config.php` и правите копию |
| `cron_wordstat.php` | Обёртка для ночного автосбора Wordstat |
| `cron_backup.php` | Обёртка для ежедневной копии базы |

База создастся сама в папке `place-data` рядом с `public_html` (вне веб-доступа).

---

## Шаг 1. Хостинг

1. Зарегистрируйтесь на **beget.com** → закажите «Виртуальный хостинг» (есть бесплатный
   пробный период; после — младшего тарифа достаточно).
2. В панели создайте сайт. Для старта подойдёт бесплатный **технический домен**
   вида `вашлогин.beget.tech`; свой домен можно привязать позже.
3. В настройках сайта выберите версию **PHP 8.x** (подойдёт и 7.4+).

## Шаг 2. Загрузка файлов

Панель → **Файловый менеджер** → папка вашего сайта → `public_html`:
удалите заглушку `index.html` хостинга, загрузите **все 5 файлов** комплекта.

## Шаг 3. Настройка config.php (2 минуты)

Сначала сделайте свой файл настроек: в файловом менеджере скопируйте
`config.sample.php` и переименуйте копию в **`config.php`** (шаблон оставьте
на месте). Правим всегда копию — сам шаблон лежит в открытом репозитории,
секретам там не место.

Откройте `config.php` в редакторе и замените:

1. `INITIAL_ADMIN_PASS` — **свой пароль администратора** (минимум 6 символов).
   Пока стоит заглушка `ПОМЕНЯЙТЕ_МЕНЯ`, система нарочно не запустится.
2. `CRON_KEY` — **обязательно** своя случайная строка от 20 символов.
   Пока стоит заглушка, запуск заданий по ссылке и самопроверка (шаг 4)
   закрыты — это защита от посторонних.
3. Wordstat пока можно не трогать — вернётесь на шаге 8.

Сохраните файл.

## Шаг 4. Самопроверка

Откройте в браузере, подставив в конец свой `CRON_KEY` из шага 3:

    https://ваш-сайт/api.php?action=selftest&key=ВАШ_CRON_KEY

Должно быть: `"итог": "ВСЁ ГОТОВО К РАБОТЕ ✓"` и список проверок.
Если какая-то проверка `ok:false` — там же написано, что исправить
(чаще всего: выбрать версию PHP повыше или дать права папке).

Без ключа страница отвечает 403: она показывает пути на сервере, версии и
число аккаунтов, поэтому открытой её оставлять нельзя. Тот же отчёт видно,
если вы уже вошли в кабинет администратором.

## Шаг 5. Первый вход

Откройте `https://ваш-сайт/`. Логин **admin**, пароль — тот, что задали в шаге 3.
Сотрудников создаёте сами: меню профиля (внизу слева) → **Пользователи** →
«Добавить аккаунт» → передаёте человеку логин и пароль. Самостоятельной
регистрации на сайте нет — случайный посетитель внутрь не попадёт.

## Шаг 6. HTTPS

Панель Beget → раздел SSL → включите бесплатный сертификат **Let's Encrypt**
для домена. Через несколько минут сайт откроется по `https://`.

## Шаг 7. Два задания в CronTab

Панель → **CronTab** → добавить задания:

**Задание 1 — автосбор Wordstat, каждый день в 03:10.**
Тип «PHP-скрипт», путь к файлу:

    /home/ВАШ_ЛОГИН/ПАПКА_САЙТА/public_html/cron_wordstat.php

**Задание 2 — резервная копия базы, каждый день в 03:40.**
Тот же тип, файл `cron_backup.php`.

Точный путь видно в файловом менеджере в адресной строке.
Альтернатива, если удобнее «по ссылке» (тип задания wget/URL):

    https://ваш-сайт/cron_wordstat.php?key=ВАШ_CRON_KEY
    https://ваш-сайт/cron_backup.php?key=ВАШ_CRON_KEY

Проверка: откройте ссылку задания 2 с ключом — в ответе `"ok":1`, а в папке
`place-data/backups` появится файл `place-ДАТА.db`. Хранится 30 последних копий;
плюс Beget сам делает ежедневные бэкапы всего аккаунта.

## Шаг 8. Подключение Яндекс Wordstat

До подключения раздел «Отслежиратор» работает на демо-данных — это нормально.

**Путь А (бесплатный API Вордстата):** на `oauth.yandex.ru` создайте приложение,
получите OAuth-токен, подайте заявку на доступ в справке Вордстата (одобряют
обычно за сутки). В `config.php`:

    define('WORDSTAT_MODE',  'wordstat');
    define('WORDSTAT_TOKEN', 'ваш-oauth-токен');

**Путь Б (Yandex Cloud, без заявки):** сервисный аккаунт с ролью
`search-api.webSearch.user`, создайте Api-Key, скопируйте `folderId`:

    define('WORDSTAT_MODE',      'cloud');
    define('WORDSTAT_TOKEN',     'ваш-api-key');
    define('WORDSTAT_FOLDER_ID', 'b1g...');

Затем: `api.php?action=selftest&key=ВАШ_CRON_KEY` — проверка «Wordstat настроен» станет ✓.
В приложении: Отслежиратор → «⚙ API» → «Сбросить демо-данные» → добавьте свои
запросы → «Обновить сейчас». Дальше каждую ночь сервер обновит всё сам.

## Шаг 9. Перенос данных из браузерной версии (если пользовались v12)

В старой версии каждый пользователь жмёт **⇩ Экспорт** у себя, в новой — входит
под своим аккаунтом и жмёт **⇧ Импорт**, выбрав свой файл. Переедет всё,
включая тренды.

## Шаг 10. Что дальше

Ежедневно — ничего: сборы и бэкапы автоматические. Рекомендую раз в месяц
нажимать «Экспорт» и класть файл в личное облако — третий уровень защиты.
Не удаляйте папку `place-data` на хостинге — там база.

**Обновления приложения:** новая версия = замена `index.html` (и `api.php`,
если указано) в `public_html`. База и данные при этом не затрагиваются.

## Если хостинг не Beget

Требования: PHP ≥ 7.4 с расширениями `pdo_sqlite` и `curl`, задачи cron,
бесплатный SSL. Подходит почти любой виртуальный хостинг; VPS не нужен.

## Частые проблемы

| Симптом | Решение |
|---|---|
| selftest отвечает 403 | Шаг 3 — задайте свой CRON_KEY (20+ символов) и добавьте `&key=` в ссылку |
| selftest: «задайте INITIAL_ADMIN_PASS» | Шаг 3 — впишите свой пароль в config.php |
| selftest: pdo_sqlite = false | В панели смените версию PHP на 8.x |
| Сайт открывается, но «Нет связи с сервером» | Проверьте, что `api.php` и `config.php` лежат рядом с `index.html`; откройте selftest с ключом |
| Cron «по ссылке» отвечает 403 | Ключ в ссылке не совпадает с CRON_KEY из config.php — либо CRON_KEY остался стандартным/короче 20 символов, тогда запуск закрыт совсем |
| Ночной сбор не сработал | Панель CronTab → журнал запусков; на сервере файл `place-data/cron.log` |
| Забыли пароль админа | Другой админ сбросит в «Пользователях»; если админ один — напишите мне, дам безопасную процедуру сброса через файл |
