# Репетитор — CRM 🎓

Приложение для репетитора: ученики, расписание занятий, оплаты (с учётом долгов)
и заметки. Работает как веб-приложение и **устанавливается на iPhone/Android
как обычное приложение** (PWA): иконка на экране «Домой», полноэкранный режим,
работа без интернета.

> Все данные хранятся **локально в браузере вашего телефона** (localStorage) и
> никуда не отправляются. В коде есть только вымышленные демо-данные для примера.

---

## 📱 Как установить на iPhone

1. Откройте ссылку на приложение в **Safari** (именно Safari, не Chrome).
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх внизу экрана).
3. Выберите **«На экран „Домой“»** (Add to Home Screen).
4. Нажмите **«Добавить»**.

Готово — на рабочем столе появится иконка. Приложение откроется на весь экран,
без адресной строки, и будет работать даже без интернета.

> Важно: добавление на экран «Домой» ещё и защищает ваши данные — iOS не удаляет
> хранилище установленных таким образом приложений.

## 🤖 Как установить на Android

Откройте ссылку в Chrome → меню (⋮) → **«Установить приложение»**.

## 🚀 Публикация (для тех, кто настраивает хостинг)

В репозитории уже настроен автодеплой на **GitHub Pages**
(`.github/workflows/deploy.yml`). Чтобы приложение стало доступно по ссылке
`https://<логин>.github.io/dabudi/`:

1. Репозиторий должен быть **публичным** (Settings → General → Change visibility),
   либо на платном тарифе GitHub.
2. В **Settings → Pages** источник (Source) выберите **GitHub Actions**
   (первый запуск workflow включает Pages автоматически).
3. При каждом пуше в ветку сборка публикуется автоматически.

**Хостинг в корне домена** (например, Netlify/свой домен) — соберите с другой
базой:

```bash
VITE_BASE=/ npm run build
# содержимое папки dist/ загрузите на хостинг
```

## 🛠 Локальная разработка

**Требуется:** Node.js 18+

```bash
npm install     # установить зависимости
npm run dev     # запустить в режиме разработки (http://localhost:3000)
npm run build   # собрать продакшн-версию в папку dist/
npm run preview # посмотреть собранную версию
npm run lint    # проверка типов TypeScript
```

Иконки приложения генерируются из `public/icon.svg`:

```bash
npm run gen:icons
```
